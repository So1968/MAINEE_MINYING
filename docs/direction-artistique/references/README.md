# Références visuelles officielles

Ces huit images constituent le cahier des charges visuel de la prochaine évolution du site de Maïné.

Elles servent à définir l’atmosphère, les matières, la lumière, la profondeur, les couleurs et la composition générale. Elles ne doivent pas être publiées comme des photographies documentaires de Maïné, de son atelier ou de ses œuvres sans validation explicite.

| Fichier | Fonction |
| --- | --- |
| `01-maquette-accueil-paysage.jpg` | Composition générale de l’accueil sur écran large |
| `02-portrait-robe-noire.jpg` | Référence de portrait et d’atmosphère |
| `03-portrait-jardin-lettre.jpg` | Référence de lumière et de jardin intérieur |
| `04-atelier-agrumes-panoramique.jpg` | Référence de geste, de matière et de plan de travail |
| `05-atelier-couture-agrumes.jpg` | Référence d’atelier et de composition verticale |
| `06-portrait-mer-photographie.jpg` | Référence pour la photographie récente |
| `07-maquette-accueil-verticale.jpg` | Composition longue de la page d’accueil |
| `08-atelier-decoupe-agrumes.jpg` | Référence du travail des peaux d’agrumes |
